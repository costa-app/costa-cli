# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.x.x   | :white_check_mark: |

All releases in the `0.x` series are actively receiving security updates.

## Reporting a Vulnerability

If you discover a security vulnerability, please **do not** open a public GitHub issue.

Instead, please report it by emailing **security@costa.app**.

You can expect:
- An acknowledgement within **2 business days**
- A status update within **7 days** as we investigate
- Credit in the release notes (if desired) once the issue is resolved

Thank you for helping keep Costa secure.
