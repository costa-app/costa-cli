# Costa CLI

Costa CLI is the official command-line interface for interacting with
[Costa](https://costa.app).

It allows you to authenticate, manage resources, and automate workflows
from your terminal.

---

## Installation

### Install Script (recommended)

```bash
curl -fsSL https://costa.app/install.sh | bash
```

### Homebrew (macOS / Linux)

```bash
brew install --cask costa
```

### Direct Download

Prebuilt binaries are available on the
[Releases](https://github.com/costa-app/costa-cli/releases)￼ page.

Download the appropriate archive for your operating system and architecture.

## Usage

After installation:

```bash
costa
```

to start.

For a list of all the commands:

```
costa --help
```
